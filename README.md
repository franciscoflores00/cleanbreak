# Clean Break

Premium, attended restroom zones for crowded events: fairs, music festivals, sporting events, and races. Free for organizers to host; guests pay per visit or buy an all-day Skip the Line wristband.

## Site

`index.html` is a single self-contained page (HTML, CSS, and a small script inline; fonts from Google Fonts). Open it in a browser to preview.

The "Book a pilot" form is a front-end preview only. It does not send submissions yet.
